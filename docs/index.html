游戏高光混剪
game-highlight-montage

把 N 段游戏精彩素材，做成一支节奏型混剪视频。核心不是"拼起来"，而是 镜头语言方法论 + 数据驱动选段 + 可复用的代码管线 —— 成品强于模板剪辑软件。

它能做什么

  • 数据驱动选段：帧差能量（YDIF）定位激战窗口 + 拉普拉斯方差锐度检测，自动剔除低清素材
  • 剪辑方法论内置：亮相拼贴 → 能量递增快剪 → 黄金分割点极限快切 → 完整表现前后呼应 → 官方收尾
  • 游戏类型适配：FPS（守望先锋 / 无畏契约 / CS:GO / 三角洲）与 MOBA（王者荣耀 / 英雄联盟）两套节奏档案
  • 平台时长参数化：微博 35s / 抖音 45s / B站 90s 预设配方，黄金分割硬约束公式
  • BGM 能量对齐：自动选窗，让视频黄金分割点落在 BGM 高能平台起点
  • BGM 一键生成：接云端 ACE-Step，批量出候选 → 滑动窗口自动评分选优 → 直接裁出可用配乐
  • BGM 风格手册：实测得出 FPS 首选「强鼓点 + 失真吉他 solo」，附数据与验收清单
  • 全代码化特效：zoom punch、紫色切帧闪光、倾斜切块拼版、电影黑边缓推…… 可迭代可复现

安装与使用

1

下载上面的 zip，解压得到 game-highlight-montage/ 文件夹。

2

把整个文件夹放进 Agent 的 skills 目录，例如 WorkBuddy 的 ~/.workbuddy/skills/。

3

对 Agent 说：「帮我做一个游戏混剪，素材在 X 目录，目标平台抖音」。

4

Agent 自动跑完：素材体检 → 选段 → BGM 对齐 → 预切 → 渲染 → 抽帧自检 → 交付成片。

# 依赖环境（脚本与渲染需要）
ffmpeg / ffprobe   # 素材体检、预切、抽帧
python3 + numpy    # 运行分析脚本
node 18+           # Remotion 渲染
npm install remotion@4.0.526 @remotion/cli@4.0.526 react@19 react-dom@19

三条铁律

准则为什么
先看画面再定段数据只是初筛，每个候选段必须抽帧目检，避免混入亮相动画 / 黑场 / 低清画面
出招帧数 > 击杀后帧数出招明确、击杀果断，约六四开；50/50 会让观众觉得"乱"
改时间线先算总长任何增删必须重新配平总时长，并复核 BGM 对齐是否仍成立

配乐怎么来的

AI 生成的配乐保证不了精确落点——这是模型特性，不是提示词写得不够好。 所以本 Skill 不指望「一次生成就完美」，而是把它变成一次搜索：

  • 批量采样：一次生成 N 个候选（不同 seed），生成时长取成片的 2 倍
  • 滑动窗口：在长曲上以 0.25s 为步长滑动，逐窗评估
  • 自动评分：切点对齐率 40 + 中位偏差 20 + 黄金分割点能量比 25 + 结构匹配 15
  • 直接落盘：得分最高的窗口裁出来，带上淡入淡出即可装配
# 先看施工单，不花钱
python scripts/bgm_generate.py timeline.json --dry-run

# 真跑：5 个候选自动选优
python scripts/bgm_generate.py timeline.json --provider acestep --n 5 --out bgm/

# 生成后复核
python scripts/bgm_onset.py 成片.mp4 timeline.json

一支 45 秒成片跑 5 个候选，按量付费约合 1 元。也可以不接 API—— --score-only 能直接给现成配乐打分，找出「收拳点软不软」这类问题。
