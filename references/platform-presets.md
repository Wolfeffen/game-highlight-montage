# 平台时长预设与参数化公式

## 平台预设表

| 平台 | 建议时长 | 依据 |
|---|---|---|
| 微博 | **35s**（≥30s 硬门槛） | 微博创作平台 30s 以上才有推流（用户实测规则） |
| 抖音 | **45s** | 30s+ 有机会获长流量推荐；剧情/娱乐类甜点区 30-45s |
| 视频号 | 30-60s | 社交裂变场景，30s-1min 传播最优 |
| 小红书 | ≤60s | 短视频笔记主流区间 |
| B站 | 1-3min | 用户接受深度内容，每 30s 设一个小高潮 |

拿不准就先问用户投放平台；多平台投放就按时长参数化公式出多版本（只需改时长参数重跑管线，选段方案可复用）。

## 时长参数化公式

设总时长 T（秒）：

```
P1 亮相拼贴   = 6s（T<40）或 8s（T≥40）—— 固定，勿超 8s（观众耐心上限）
P3 极限快切   = 3.0-3.5s，且收拳点 = T × 0.618（黄金分割，硬约束）
P5 收尾+端卡  = 4.5-6s（LOGO 3-3.5s + 端卡 1.5s）
P4 完整表现   = 8-12s（1-2 段完整操作）
P2 快剪主体   = T - 以上各项（填充段，段数 = P2时长 ÷ 1.0~1.5s/段）
```

## 常用配方

### 35s（微博）
- P1 6s → P2 11.4s（约 9 段）→ P3 3s（收拳 21.6s=35×0.618）→ P4 8s（1段）→ P5+端卡 6.6s

### 45-47s（抖音，已验证）
- P1 8s → P2 16-19s（12 段，含 1 个 3-4.5s 前后呼应急奏段）→ P3 3-3.5s（收拳 ≈ T×0.618）→ P4 11.5s（2 段）→ P5+端卡 5s

### 60s（竖屏 9:16，小红书/视频号上限）—— 用户实测 ChatGPT 跑通
- P1 8s → P2 25.9s（约 21 段 @1.25s）→ P3 3.2s（收拳 **37.1s** = 60×0.618）→ P4 17.4s（约 3 段完整操作）→ P5+端卡 5.5s
- 推导：P2 = 收拳点 − P1 − P3时长；P4、P5 吃掉剩余 22.9s。60s 时 P4 必须放大到 17s 上下
  （不是 45s 版的 11.5s），否则后半段会空。

### 90s（B站）
- P1 8s → P2 45s（分 2 个子段落，中间插入 1 个完整段作呼吸点）→ P3 3.5s（收拳 55.6s）→ P4 24s（3 段）→ P5+端卡 9.5s
- B站长版注意每 30s 安排一个节奏高潮（完整段或极限快切）。

## 竖屏（9:16）适配

**画幅**：1080 × 1920。

**安全区**（抖音/视频号 UI 会遮挡边缘，别把关键信息放进去）：

| 区域 | 遮挡情况 | 建议 |
|---|---|---|
| 顶部 0-15% | 状态栏、部分标题 | 不放 LOGO |
| **底部 0-20%** | 昵称、描述文案、进度条 | **文字/LOGO 绝不放这里** |
| 右侧 12% 宽 | 点赞/评论/分享竖排按钮 | 主体避开右缘 |

**横屏素材进竖屏的三种处理**（按推荐顺序）：

1. **上下模糊背景填充**（最常用）：原画居中，上下用同帧放大后的高斯模糊补满。
   保留完整画面信息，不丢操作细节——**FPS 混剪首选**，因为裁切会切掉 HUD 和准星周围信息。
2. **居中裁切**：只取中间 9:16 区域。构图最干净，但会丢掉两侧画面，
   横屏素材中偏离中心的击杀目标可能被切掉。
3. **关键主体裁切**：按画面主体位置动态裁。效果最好但实现复杂，需逐帧判断。

**竖屏专属注意**：

- 拼版（P1 亮相的多格拼贴）在竖屏下应改成 **横条块竖排**——每条是斜切平行四边形
  横向长条，4 条左右从上到下叠放，条间留窄缝，整体斜角统一（约 5-8°）并逐条错位。
  实测案例见 `references/p1-vertical-collage-example.jpg`（莫伊拉 60s 竖屏 P1 亮相，
  ChatGPT 按本 Skill 产出）：同角色贯穿四格保持视觉连贯；每格左下角两级文字——
  小字来源标签（如"全场最佳"）+ 大字系列名（橙色描边）；上下黑边正好让出竖屏 UI 安全区。
- 已知小坑：标题字用橙色描边时，若该格背景是亮黄色能量特效（如莫伊拉 开关球），
  橙字压亮黄对比度会不足——要么给字加深色描边/投影，要么错开该格的选帧。
- 端卡文字字号要按 1080 宽重新定，横屏迁移过来的字号在竖屏会偏小。
- 收拳点、P3 快切节奏与横屏一致，不受画幅影响。

> 状态：60s 竖屏已由用户在 ChatGPT 上跑出成片（P1 亮相截图已存档），结构思路清晰。
> 画幅/安全区为通用规范，拼版竖排已有实测截图佐证。

## 配平技巧

- 延长某段后需要补时：优先删 P3 中最弱碎片（0.2-0.3s 级）、微调 LOGO 段（4.0→3.5s），不动 P4 完整表现。
- 黄金分割点是硬约束：T 变化后，P3 位置跟着平移，保证收拳帧落在 T×0.618。
- BGM 重新对齐：T 变化后重新跑 BGM 能量分析，让黄金分割点仍落在高能平台起点附近。
